One original line of office comedy — the reply-all thread everyone dreads, where asking to be removed only spawns more replies-all.

> I replied-all "please remove me from this thread" — and got twelve replies-all asking to be removed too.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 104 characters, within the 200-character cap.
